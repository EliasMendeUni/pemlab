# pemlab

Python-Package für die Messdatenanalyse und die Erstellung von (LaTeX-)Protokollen
in der Physikalischen und Elektronischen Messtechnik.

> Status: frühe Entwicklung (v0.1.0) – die API ist noch nicht stabil.

## Installation

```bash
pip install git+https://github.com/<username>/pemlab.git
```

Für die Entwicklung:

```bash
git clone https://github.com/<username>/pemlab.git
cd pemlab
py -m venv .venv
.venv\Scripts\activate
pip install -e ".[dev]"
```
